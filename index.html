Gestione bici

Come si ottiene la chiave
  1. Su GitHub, con l'account che ha accesso al sito: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nome: gestione bici. Scadenza: la più lunga disponibile (va rifatta quando scade).
  3. Repository access → Only select repositories e scegliere soltanto il repository del sito.
  4. Permissions → Repository permissions → Contents → Read and write. Nient'altro.
  5. Generare, copiare la chiave e incollarla qui sopra. Su GitHub non si rivede più: se si perde, se ne fa un'altra.
